# Emulating CPU
	- ![](https://bugzmanov.github.io/nes_ebook/images/ch3/image_4_opcodes.png){:height 305, :width 609}
	- 6502のコマンドは6グループに分けられ、全体で64つのコマンドを持つシンプルなCPUアーキテクチャ
	- 150種類のマシンコード命令を実装することになる
	- ファミコンのカスタムチップ2A03は6502がベース
	- しかし、明確に異なる部分がある
		- 6502に対して追加で110のオプコード (命令識別番号) が存在する
			- ただその1/3は仕様しない
		- ボード上にAPUを備えている
		- 計算用の十進数モードは持たない
